# 오늘의 건강 한 줄 — 출처 대장

> 코드: `src/app/(main)/@today/health-tips.ts` · 가드: `health-tips.test.ts`
> 확인일: **2026-09-05**. 문장을 추가·교체할 때 이 표를 함께 갱신한다.

## 왜 발췌인가

2026-09-05 문구 QA 에서 지어낸 문장 30개 중 8개가 "혈당과 기분이 함께 좋아져요" 처럼 효과를 단정하고
있었다. 앱의 다른 건강 정보(생활 관리 정보)는 PubMed 근거 등급을 붙여 "도움이 된다고 알려져 있어요" 로
헤지하는데 이 목록만 근거 없이 단정했다. 지어낸 문장은 "누가 그랬는데?" 에 답이 없다 —
공공기관 원문을 그대로 발췌하고 문장마다 출처를 붙이면 문장이 방패를 얻는다.

## 규칙

1. **공공누리 제1유형(출처표시)** 으로 개방된 기사만 쓴다. B2B 유료화가 예정돼 있어 2·4유형(상업적 이용 금지)은
   못 쓴다. 유형은 **기사 단위로** 확인한다 — 같은 식약처 자료라도 카드뉴스는 4유형이었다(아래 "제외" 참조).
   확인 방법: 기사 HTML 에 `공공누리 제1유형(출처표시)의 조건` 문구가 있는지 본다(`scripts/copy-qa` 와 같은 curl+정규식).
2. 문장은 **원문 그대로**. 허용하는 손질은 문두 접속부사(또한·특히·아울러·먼저·가령·이에 앞서) 제거와
   특수문자 정규화(`&middot;` → `·`)뿐이다. 눈높이에 안 맞으면 다듬지 말고 **빼고 다른 문장을 고른다**.
3. 원문이라도 효과 단정형·약과의 비교·용량 지시·음성 판정 문구는 고르지 않는다(테스트가 거른다).
   예: 걷기 기사의 "우울증 위험을 감소시키고 … 효과가 있는 만큼" 은 성과 주장이라 뺐다.
4. 출처 표기는 공공누리 안내대로 **기관명·저작물명·링크** 를 문장 옆에 둔다(오늘 복약 화면 하단).
